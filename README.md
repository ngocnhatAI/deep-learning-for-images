# 🧠 Deep Learning for Image Tasks

This repository applies **Deep Learning** techniques to solve three major computer vision problems:  
- **Image Classification**  
- **Image Segmentation**  
- **Object Detection**  

It includes complete pipelines for data preprocessing, training, evaluation, and inference using PyTorch Lightning and Ultralytics YOLO.

---

## ⚙️ Requirements

- Python 3.8+
- PyTorch
- PyTorch Lightning
- torchvision
- segmentation-models-pytorch
- albumentations
- ultralytics
- OpenCV
- scikit-learn
